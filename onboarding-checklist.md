# Onboarding Checklist — New Employee (Sample)
Employee (sample): Sample User A | Department (sample): Sample Department | Start date (sample): YYYY-MM-DD | Requested by (manager): ________

## Before day one
- [ ] Written request received from the manager (see templates/new-user-request-form.md).
- [ ] User account created with a standard username pattern. [NEEDS INPUT: your organisation's username pattern]
- [ ] Email account created, if the role needs one.
- [ ] ERP access requested, with the correct role only (not admin by default).
- [ ] Computer / laptop prepared, updated, and checked.
- [ ] Required software installed and tested.
- [ ] Network / Wi-Fi access confirmed.
- [ ] Printer access confirmed, if needed.
- [ ] Desk, phone, and any shared equipment assigned and recorded in the asset list.

## On day one
- [ ] User shown how to sign in, and password rules explained.
- [ ] User shown how to raise a helpdesk ticket.
- [ ] User shown where shared files and the ERP system are.
- [ ] Manager confirms the user can work. Any problem is logged as a ticket the same day.
