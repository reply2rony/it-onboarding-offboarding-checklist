# User Account SOP — Create, Change, Disable

## 1. Create an account
1. Receive a written request from the manager. No verbal-only requests.
2. Create the account with the standard username pattern and a temporary password.
3. Give only the access the role needs. Do not give admin rights "just in case".
4. Record the account in the user list with: name, department, start date, systems granted.
5. Tell the user and the manager that the account is ready, and that the temporary password must be changed on first sign-in.

## 2. Change an account (role change / transfer)
1. Receive a written request for the new role.
2. Remove access for the old role first, then add access for the new role.
3. Update the user list and tell the manager.

## 3. Disable an account (leaver)
1. Receive a written leaver request.
2. Disable the account on the last working day. Do not share the password with anyone.
3. Remove ERP, VPN, and email access as per policy.
4. Record the disable date and who requested it.
