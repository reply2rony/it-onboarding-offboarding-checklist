# IT Onboarding and Offboarding Checklists

Checklists for setting up a new employee's IT access, and for safely removing access when someone leaves. Nothing here uses real employee data — all examples are samples.

## Why this matters
Most IT security problems with accounts come from two moments: a new starter who waits days for access, and a leaver whose access is never removed. A checklist prevents both.

## Files
- `onboarding-checklist.md` — everything to set up before and on day one.
- `offboarding-checklist.md` — everything to remove or return on the last day.
- `user-account-sop.md` — the standard steps for creating, changing, and disabling an account.
- `templates/` — the two request forms a manager fills in. No IT work starts without a written request.
