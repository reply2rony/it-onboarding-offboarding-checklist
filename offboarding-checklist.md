# Offboarding Checklist — Leaver (Sample)
Employee (sample): Sample User B | Last working day (sample): YYYY-MM-DD | Requested by (manager): ________

## On the last working day
- [ ] Written leaver request received from the manager.
- [ ] User account disabled (not deleted on day one, so files and mail can be handled safely).
- [ ] Email access handled as per company policy. [NEEDS INPUT: your organisation's email-retention rule]
- [ ] ERP access removed.
- [ ] VPN / remote access removed.
- [ ] All equipment returned and recorded in the asset list (laptop, charger, phone, keys, ID card).
- [ ] Shared passwords the person knew are changed, if any.
- [ ] Manager confirms all returns. Any missing item is reported the same day.

## After 30 days (or as per policy)
- [ ] Account and data handled as per company policy (archive or delete). [NEEDS INPUT: your organisation's retention period]
